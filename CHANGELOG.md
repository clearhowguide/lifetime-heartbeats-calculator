# Changelog

All notable changes to Lifetime Heartbeats Calculator are documented here.

## [1.0.0] - 2026-08-12

### Added

- Lifetime-heartbeats estimation mode.
- Heartbeats-to-years conversion mode.
- Human and elephant illustrative presets.
- One-billion and two-billion heartbeat presets.
- Human-readable and exact numerical results.
- One-billion-heartbeats visual comparison.
- Faster/slower heart-rate scenarios.
- URL-based shareable calculator state.
- Copy-result functionality.
- Web Share API support with clipboard fallback.
- Input validation.
- Responsive interface.
- Keyboard-accessible mode tabs.
- ARIA live regions.
- Reduced-motion support.
- Local-only calculation model.
- Privacy documentation.
- Mathematical regression checks.
- Privacy source check.
- Citation metadata.
