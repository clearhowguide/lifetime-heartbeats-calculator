# Support

Thank you for using Lifetime Heartbeats Calculator.

## Bugs

For reproducible software bugs, open a GitHub issue.

Please include:

- browser;
- operating system;
- calculator mode;
- input values;
- expected result;
- actual result;
- steps to reproduce.

## Feature requests

Feature requests can also be submitted through GitHub Issues.

Please explain:

- what problem the feature solves;
- why it belongs in this calculator;
- how it would remain educational and privacy-conscious.
