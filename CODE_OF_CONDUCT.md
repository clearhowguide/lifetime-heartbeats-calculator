# Contributor Code of Conduct

## Our pledge

We want Lifetime Heartbeats Calculator to be a welcoming, respectful and useful open-source project.

## Our standards

Examples of positive behavior include:

- using welcoming and inclusive language;
- respecting different viewpoints;
- accepting constructive feedback;
- focusing on what is best for the project and its users;
- helping beginners understand technical decisions;
- showing empathy toward other contributors.

Unacceptable behavior includes:

- harassment;
- threats;
- insults or personal attacks;
- discriminatory language;
- publishing private information without permission;
- deliberately misleading users about scientific or medical claims;
- disruptive behavior that harms the project community.

## Project-specific expectations

Because this project deals with heart rate and lifespan arithmetic, contributors must be especially careful not to present calculator output as:

- medical advice;
- diagnosis;
- personal lifespan prediction;
- proof that a fixed heartbeat budget exists.

## Enforcement

Project maintainers may remove, edit or reject comments, commits, issues, pull requests and contributions that do not align with this Code of Conduct.

## Reporting

If you experience unacceptable behavior, use the official ClearHowGuide contact page:

https://clearhowguide.com/en/contact/

## Goal

Keep the project useful, respectful, scientifically careful and accessible to everyone.
